# DataTube — design system

Apple-like and quiet: the content (the sheets) is the interface. Built from the `ui-ux-pro-max` recommendation (Minimalism & Swiss: monochrome, one accent, system type, no decoration) and Apple's HIG principles (system font, grouped surfaces, hairlines, segmented controls, instant press feedback, paired light/dark, reduced motion).

## Rules

- **Tokens only.** Colors come from `app/globals.css` (`bg`, `surface`, `label`, `label-2`, `label-3`, `separator`, `fill`, `fill-2`, `accent`, `positive`, `caution`, `negative`, `indigo`) as Tailwind classes: `bg-surface`, `text-label-2`, `border-separator`, `text-accent`… Never a raw hex, never `neutral-*`/`zinc-*`/`gray-*`/`blue-*`/`red-*` Tailwind palettes, never `bg-white`/`text-black`.
- **Controls are the shared classes**, not ad-hoc utility strings: `.btn .btn-primary | .btn-secondary | .btn-plain | .btn-destructive`, `.field` (inputs, selects, textareas), `.card`, `.rows` (hairline separators between children), `.segmented` + `.segment` (active one gets `aria-current="page"` for links or `aria-selected="true"` for tabs), `.status .status-done|active|review|caution|negative|idle` (dot + word), `.notice .notice-caution|notice-negative`, `.ts` (a timestamp that seeks the player), `.code-block`. Type: `.large-title` (one per page, the page's h1), `.title-2` (section h2), `.headline`, `.subhead` (secondary 13px), `.eyebrow` (small uppercase section label).
- **One primary action per screen** (`.btn-primary`); everything else `.btn-secondary` or `.btn-plain`.
- **Icons: `lucide-react` only**, 15–16px, default stroke, always next to a text label (icon-only controls need `aria-label`). Never an emoji in the UI chrome.
- **Sheet headings keep their emoji in the data and the exports** (the spec's format), but the app renders them without it: `components/Markdown.jsx` strips a leading emoji from headings.
- **No shadows beyond the hairline** of `.card`, no gradients, no colored pills, no `rounded-full` chips, no uppercase buttons.
- **Spacing on a 4/8 grid.** Page gutter `px-4 md:px-10`, page top `pt-6 md:pt-10`, sections `mt-8`, inside cards `p-4` (rows `px-4 py-3`).
- **Layout:** content column `max-w-5xl` (tables/settings), reading sheets capped at `72ch` by `.sheet`.
- **Motion:** only the built-in 150 ms color transitions and the 0.97 press scale of `.btn`; nothing else animates (reduced motion is handled in globals.css).
- **Accessibility:** every input has a visible `<label>` or an `aria-label`; state is never color alone (`.status` = dot + word); focus rings come from `:focus-visible` in globals.css — never remove them; async buttons are disabled while pending and say what they do ("Queuing…").
- **Numbers:** `tabular-nums` on durations, counts and costs; costs always through `formatUsd`.

## App shell (`app/layout.js`, `components/SidebarNav.jsx`, `components/ThemeTree.jsx`)

- **Desktop (md+):** a 240px sidebar, `sticky top-0 h-dvh overflow-y-auto`, background `bg-[var(--sidebar)] backdrop-blur-xl`, right hairline `border-r border-separator`. Top: the wordmark — a 22px rounded-md `bg-accent` square with a white lucide `Library` icon (13px) + "DataTube" (`headline`). Then the nav: rows `h-8 px-2 rounded-md flex items-center gap-2 text-[13px]`, icon 16px `text-accent`, label, count right-aligned `text-label-2 tabular-nums`. Items: Library (`LibraryBig`), To review (`Inbox`, count, the count shown in `text-accent font-medium` when > 0), Settings (`Settings`). Hover `bg-fill`; the current route `bg-fill-2 font-medium` (client component with `usePathname`; `/` is active only on exactly `/`, `/review` and `/settings` by prefix). Then an `.eyebrow` "Themes" (`mt-6 mb-1 px-2`) and the tree: rows like nav rows with a `Folder` icon (`text-label-2`), children indented (`pl-6`, no icon), each row's count; a parent's count is its own videos + its children's (computed in the component from the tree prop). The active theme row (`/themes/<id>`) gets `bg-fill-2`. Empty tree: `subhead` "No themes yet — they appear as videos are sorted."
- **Mobile (< md):** a sticky top bar (`sticky top-0 z-20 bg-[var(--sidebar)] backdrop-blur-xl border-b border-separator px-4`): the wordmark row, then the three nav items as a horizontally scrolling row of `.segment`-like links (`aria-current` on the active one), then a `<details>` "Themes" disclosure (summary: `.eyebrow` + a `ChevronDown` that rotates when open) holding the same tree. No page-level horizontal scroll.
- `<main>`: `min-w-0 flex-1 px-4 pb-16 pt-6 md:px-10 md:pt-10`.
- `app/not-found.js`: centered in main — `SearchX` icon 28px `text-label-3`, `.title-2` "Not found", `.subhead` "This page does not exist, or the item was removed.", `.btn .btn-secondary` link "Back to Library".

## Library (`app/page.js`, `components/ImportForm.jsx`, `components/VideosTable.jsx`, `components/StateBadge.jsx`)

- Header: `.large-title` "Library"; under it `.subhead` with the counts ("5 videos · 0 in progress · 1 to review · 1 failed", tabular).
- Import: a `.card p-4` — `<label>` "Add videos" (`headline`) + `.subhead` "One link per line — a video, a playlist or a channel."; the textarea `.field w-full font-mono text-[13px]` (4 rows, same placeholder); a row with the result on the left and `.btn .btn-primary` "Import" (lucide `Plus`) on the right; pending label "Reading links…". The result line (`aria-live="polite"`): `CheckCircle2` `text-positive` + "2 imported · 1 already in the library · 1 line not recognised"; an error: `AlertCircle` `text-negative` + message. Per-link errors under it as a `.rows` list in `text-[13px]`.
- The YouTube pause banner: `.notice .notice-caution` with a `Clock` icon.
- Toolbar (`mt-8`): the filters as a `.segmented` (links, `aria-current="page"` on the active one) inside a `max-w-full overflow-x-auto` wrapper; the search on the right on desktop, full width below on mobile: a `.field` with a `Search` icon inside (absolute, `text-label-3`, `pl-8`), placeholder "Search", `aria-label` "Search titles, sheets and transcripts".
- `VideosTable` (props unchanged: `videos`, `empty`): md+ a `.card overflow-hidden` holding a `<table>`: header row `text-[12px] font-medium text-label-2`, no fill, hairline below; rows `.rows`-style hairlines (`border-t border-separator` on each `tr + tr`), `h-12`, hover `bg-fill/50`; the title cell a link (`font-medium text-label hover:text-accent`), secondary cells `text-label-2`, length and cost `tabular-nums` right-aligned for cost; the theme cell a link in `text-label-2 hover:text-accent`, "—" in `text-label-3` when none. Below md: a `.card .rows` list — each item a link block `px-4 py-3`: title (`font-medium`), then a `.subhead` line "Channel · 12:34 · Theme", the `StateBadge` on the right. Empty: centered `.subhead` in a `.card p-8` with the `empty` text.
- `StateBadge` (props unchanged): `<span className="status status-…">Label</span>` — done → `status-done`; queued → `status-idle`; fetching/summarizing/classifying → `status-active`; no_transcript → `status-caution`; failed → `status-negative`; done + proposed → `status-review` "To review". Labels: Queued, Fetching transcript, Summarizing, Sorting, Done, No transcript, Failed, To review.

## Video (`app/videos/[id]/page.js`, `components/VideoWorkspace.jsx`, `components/Markdown.jsx`, `components/ActionButton.jsx`, `components/CopyButton.jsx`, `components/ThemePicker.jsx`)

- Back link: `.btn .btn-plain -ml-2` with `ChevronLeft` + "Library".
- Header: `.large-title` title; `.subhead` facts line ("Trader Joe · 1:02:33 · en · 2026-04-12 · $0.01 spent"); the `StateBadge` right-aligned on desktop, under the title on mobile. Error: `.notice .notice-negative` with `AlertTriangle`.
- Toolbar (`mt-5 flex flex-wrap gap-2`): Copy Markdown (`CopyButton`, lucide `Copy`, "Copied" with `Check` for 1.5 s), Download .md (`<a className="btn btn-secondary">` with `Download`), Regenerate summary (`ActionButton`, `RefreshCw`), Retry (`ActionButton` variant primary, `RotateCcw`) when failed/no_transcript, and "Open on YouTube" (`.btn .btn-plain`, `ArrowUpRight`, `target=_blank rel=noreferrer`).
- Theme (`mt-6 .card`): one row `px-4 py-3 flex items-center justify-between gap-3`: left `.eyebrow` "Theme" over the current path (a link to the theme, `font-medium`) and a `.subhead` ("Sorted by Jev · 80% sure", "Filed by hand", "Waiting in To review", "Not sorted yet"); right a `.btn .btn-secondary` "Change" (`FolderInput`) that toggles the picker open under a hairline (progressive disclosure — the picker is closed by default). Picker (`ThemePicker`, same actions): a row "Move to" `<select className="field">` + `.btn .btn-secondary` "Move"; a row "New theme" `.field` Parent (optional) + `.field` Name + `.btn .btn-secondary` "Create and move"; every field has an `aria-label`; the error under them in `text-negative text-[13px]`.
- Workspace (`mt-6 grid gap-6 lg:grid-cols-[minmax(0,1fr)_minmax(0,1fr)]`): the player `aspect-video rounded-xl overflow-hidden bg-black` (sticky `lg:top-6` in the left column); the right column: a `.segmented` with two `role="tab"` buttons "Sheet" / "Transcript" (`aria-selected`), then:
  - Sheet: `<Markdown markdown={sheet} onSeek={seek} />` inside a `.card p-5 md:p-6`. The page passes the sheet WITHOUT its title and metadata line (`summaryBody(video.summary)` from `@/lib/pipeline/markdown.mjs`) — the page header already shows them; Copy/Download still use the full file.
  - Transcript: a `.field` search with the `Search` icon ("Find in the transcript"), then a `.card .rows max-h-[70vh] overflow-y-auto` list; each line a full-width button `px-4 py-2 text-left flex gap-3 hover:bg-fill/60`: the stamp in `font-mono text-[12px] text-accent tabular-nums w-14 shrink-0`, the words in `text-[14px]`. Empty states in `.subhead`.
- `Markdown` (props unchanged: `markdown`, `onSeek?`): with `onSeek`, `#t=` links render as `<button className="ts">`; other links `text-accent hover:underline`, `target=_blank`. Headings `h1`–`h3` render their text without a leading emoji (strip `^[\p{Extended_Pictographic}️‍\s]+` from the first string child).
- `ActionButton` (props: `action`, `label`, `pendingLabel?`, `variant?` = "primary" | "secondary" (default) | "destructive", optional `icon` — an element such as `<RefreshCw aria-hidden="true" />` rendered before the label; an element, not a component, because Server Components can only pass serializable props). Error: `text-negative text-[13px]` next to it, `role="alert"`.
- `CopyButton` (props: `text`, `label?`): `.btn .btn-secondary`, `Copy` icon → `Check` icon + "Copied".

## Settings (`app/settings/page.js`, `components/SettingsForm.jsx`)

macOS System Settings grouping: each section is a `.eyebrow` title (`mb-2 px-1`) above a `.card .rows`; rows `px-4 py-3 flex items-center justify-between gap-4`, label left (`text-[14px]`), value/control right; helper text as `.subhead` under the label. Sections, in order:
1. **Models** (the form): "DeepSeek model" + select; "Auto-sort threshold" (helper: "Jev files a video by itself when it is at least this sure; below, it waits in To review.") + `.field w-20 text-right tabular-nums` number + "%"; last row: the result ("Saved" with `Check` `text-positive`, or the error) + `.btn .btn-primary` "Save".
2. **API keys**: "DeepSeek" / "TypeSafe (Jev)" → `.status status-done` "Set", or `.status status-negative` "Missing" with a `.subhead` under the label: "Add DEEPSEEK_API_KEY to .env.local, then restart npm run dev". Never the value.
3. **Tools**: "yt-dlp" / "deno" → the version in `font-mono text-[13px] text-label-2`, or `.status status-negative` "Missing" + `.subhead` with the command `brew install yt-dlp deno` in `font-mono`.
4. **Spend**: "This month" / "All time" → `formatUsd` in `tabular-nums`.
5. **Claude Code**: a row with the `.subhead` explanation ("Run once in a terminal; Claude Code can then search and read your sheets.") and under it the `.code-block` with `claude mcp add datatube -- node <absolute path>` + a `CopyButton` (label "Copy command").

## Spend (`app/spend/page.js`, `components/SpendBars.jsx`, `components/BudgetBanner.jsx`; nav item in `components/SidebarNav.jsx`; budget field in `components/SettingsForm.jsx`)

Every amount on this page uses `formatUsdPrecise` (four decimals, truncated): per-call costs are fractions of a cent and "< $0.01" would say nothing. Elsewhere (Library, video page, banners) `formatUsd` stays.

- Nav: "Spend" (lucide `Wallet`) between To review and Settings, desktop and mobile.
- Header: `.large-title` "Spend" + `.subhead` "What the DeepSeek and Jev calls cost, recorded call by call."
- `BudgetBanner` (server component, prop `budget` = `budgetStatus(db, now)`): nothing for `none`/`ok`; `warning` → `.notice .notice-caution` + `AlertTriangle`: "You have used 82% of this month's budget ($4.10 of $5.00)."; `reached` → `.notice .notice-negative` + `PauseCircle`: "Monthly budget reached ($5.00 of $5.00) — summaries and sorting are paused until Oct 1, or until you raise the budget in Settings." (link to /settings). Also shown on the Library under the YouTube pause notice.
- Overview: a `grid gap-3 md:grid-cols-3` of `.card p-4`: `.eyebrow` Today / This month / All time, the amount `text-[26px] font-semibold tracking-tight tabular-nums`, a `.subhead` with the number of calls where useful. This month with a budget: a 6px bar (`rounded-full bg-fill` track, fill `bg-accent`, `bg-caution` at warning, `bg-negative` when reached, width = min(usedPermille, 1000) / 10 %) and "of $5.00 · resets Oct 1"; without a budget: a `.btn-plain` link "Set a monthly budget" to /settings.
- DeepSeek account (`.card .rows`): "Balance" → the amount (USD via `formatUsdPrecise`; another currency: the number + its code, no comparison); when USD and not `started`: "Real spend since Sep 27" and "Recorded by DataTube" (both `formatUsdPrecise`), and "Difference" (real − recorded) with a `.subhead`: "A gap means a call was billed but not recorded, or a price in the table is off."; when `started`: `.subhead` "Starting point saved — the comparison appears after the next calls."; no key: "Add DEEPSEEK_API_KEY to .env.local to read the balance."; error: "Could not read the balance — <message>". Never the key.
- Last 30 days: `.card p-4` + `SpendBars` (props: `days` = `spendByDay(db, now, 30)`): a 128px-high flex row of bars (`bg-accent`, rounded top 2px, gap 2px, a zero day is a 1px `bg-separator` stub), each with `title`/`aria-label` "Sep 24 · $0.0050"; under it the first, middle and last day in `.subhead`; all zero → `.subhead` "No spend in the last 30 days."
- "By provider" and "By use" (`.title-2` + `.card` tables like VideosTable): provider rows DeepSeek / Jev (TypeSafe) — calls, tokens in, tokens out (`toLocaleString("en-US")`), cost; use rows with plain labels — summary "Video sheet", summary_notes "Long video · part notes", summary_merge "Long video · merge", theme_proposal "Theme name proposal", classify "Theme sorting", theme_sheet "Theme sheet", theme_sheet_part "Large theme · partial sheet" (unknown feature → its raw name) — provider, calls, cost.
- "Most expensive videos" (top 10, link to the video; a deleted one reads "Deleted video" + its id) and "Most expensive theme sheets" (link to the theme; deleted → "Deleted theme").
- "Latest calls" (50): time ("Sep 27, 14:05"), use, target (video title link, theme path link, or —), model, tokens in → out, cost; in a `.card` with `overflow-x-auto` and a `min-w-[720px]` table.
- No call at all: one `.card p-8` centered `.subhead` "No API call yet — costs appear here as videos are summarized." instead of the tables.
- The page does not auto-refresh (each load reads the DeepSeek balance over the network).
- Settings: a "Monthly budget" row in the Models form — `<input name="monthlyBudget" inputMode="decimal">` with a "$" prefix, `.field w-28 text-right tabular-nums`, default = the current budget without the "$" (empty when none), helper "Summaries and sorting pause when this month's spend reaches it. Leave empty for no budget." The Spend section of Settings keeps This month / All time and gains a `.btn-plain` link "See all spending" to /spend.
