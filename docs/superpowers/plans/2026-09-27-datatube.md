# DataTube — plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal :** une app Next.js locale. On y colle des liens YouTube (vidéos, playlists, chaînes). Elle en tire les transcripts, écrit une feuille de connaissances par vidéo (DeepSeek), range chaque vidéo dans un thème (Jev), consolide une feuille par thème, et sert le tout en export Markdown et par un serveur MCP.

**Architecture :**
- Trois process sur une seule base SQLite (`data/datatube.db`) :
  - l'app Next (lecture et gestes) ;
  - un worker Node qui traite la table `Job` une étape à la fois (fetch → summarize → classify) ;
  - un serveur MCP en lecture seule, lancé par Claude Code.
- `yt-dlp` fait tout ce qui touche YouTube.
- DeepSeek écrit, Jev (TypeSafe System One) classe.

**Tech Stack :**
- Next.js 16 (App Router), React 19, JavaScript, Tailwind v4 ;
- better-sqlite3 (FTS5), zod, vitest ;
- react-markdown + remark-gfm, @modelcontextprotocol/sdk, concurrently ;
- yt-dlp + deno (brew).

**Spec :** `docs/superpowers/specs/2026-09-27-datatube-design.md` (à lire en entier avant la tâche 0). La méthode d'origine est dans `docs/reference/ytquest/`, en lecture seule.

## Qui exécute quoi

Chaque tâche porte une étiquette de modèle (règle de Robin) :
- **[FABLE/OPUS]** : la session principale l'implémente elle-même. Ce sont les contrats de données, l'argent (coûts), les prompts anti-hallucination, la file de jobs (concurrence, reprises) et la revue finale.
- **[SONNET]** : la session principale la confie à un sous-agent (`model: sonnet`), avec le texte COMPLET de la tâche et les « Global Constraints ». Elle relit ensuite le diff ligne à ligne avant de passer à la tâche suivante.

## Global Constraints

- **Next.js 16 n'est pas celui que tu connais :**
  - avant d'écrire du code Next, lis les guides de `node_modules/next/dist/docs/` (Server Actions, Route Handlers, `params` / `searchParams` qui sont des **Promise**, `serverExternalPackages`, `connection()`) ;
  - respecte les avis de dépréciation.
- **JavaScript uniquement :**
  - `app/` et `components/` sont en `.js` / `.jsx` et peuvent importer avec `@/` ;
  - `lib/`, `worker/` et `mcp/` sont en `.mjs` avec des imports **relatifs uniquement**, car ils tournent aussi sous Node pur (worker, MCP).
- **Tout en anglais :** l'interface, les feuilles (résumés et feuilles de thème), le code, les commits.
- **Argent :**
  - les coûts sont des **micro-USD entiers**, calculés en BigInt et arrondis une seule fois, sur le total d'un appel ;
  - un coût ne se stocke jamais en float ;
  - l'affichage tronque (`formatUsd`).
- **Secrets :**
  - `DEEPSEEK_API_KEY` et `TYPESAFE_API_KEY` vivent dans `.env.local` seulement ;
  - ils ne sont jamais affichés, loggés, stockés en base ni envoyés au navigateur ;
  - Settings montre seulement « set / missing ».
- **Tests (vitest) :** jamais de réseau, jamais `yt-dlp`, jamais l'horloge réelle. `now` est injecté partout, en millisecondes.
- **Dates :** chaînes ISO UTC en base (`new Date(ms).toISOString()`).
- **Règles des feuilles** (le produit, à ne jamais affaiblir) :
  - le transcript est la seule source ;
  - chaque point porte `[MM:SS] "exact words"` ;
  - une section vide dit exactement `Not in the video` (`Not in the videos` pour un thème) ;
  - pas de connaissance extérieure ;
  - la sortie est en anglais, les citations restent dans la langue parlée avec la traduction anglaise entre parenthèses.
- **Serveur MCP :** rien sur stdout sauf le protocole. Les logs passent par `console.error`.
- **Commits :** un commit par tâche, message en anglais au format `type(scope): …`.

`lib/settings.test.mjs` :

```js
import { describe, expect, it } from "vitest";
import { openDb } from "./db.mjs";
import { SETTING_DEFAULTS, getSetting, readSettings, setSetting, writeSettings } from "./settings.mjs";

describe("settings", () => {
  it("reads the defaults when nothing is stored", () => {
    expect(readSettings(openDb(":memory:"))).toEqual(SETTING_DEFAULTS);
  });

  it("keeps a valid value and falls back on an invalid one — never a surprise minimum", () => {
    const db = openDb(":memory:");
    writeSettings(db, { jevThresholdPermille: 750 });
    expect(readSettings(db).jevThresholdPermille).toBe(750);
    setSetting(db, "jevThresholdPermille", null); // Number(null) would be 0: it must not be
    expect(readSettings(db).jevThresholdPermille).toBe(SETTING_DEFAULTS.jevThresholdPermille);
    setSetting(db, "deepseekModel", "gpt-9");
    expect(readSettings(db).deepseekModel).toBe(SETTING_DEFAULTS.deepseekModel);
  });

  it("refuses to write an out-of-range threshold or an unknown model", () => {
    const db = openDb(":memory:");
    expect(() => writeSettings(db, { jevThresholdPermille: 1001 })).toThrow();
    expect(() => writeSettings(db, { deepseekModel: "gpt-9" })).toThrow();
  });

  it("stores any JSON value under a key", () => {
    const db = openDb(":memory:");
    setSetting(db, "queuePausedUntil", 1_790_000_000_000);
    expect(getSetting(db, "queuePausedUntil")).toBe(1_790_000_000_000);
    expect(getSetting(db, "missing")).toBeNull();
  });
});
```

```js
// The library's contract. A change here is a new SCHEMA_VERSION and a migration step in db.mjs.
export const SCHEMA_VERSION = 1;

export const SCHEMA = `
CREATE TABLE IF NOT EXISTS Theme (
  id INTEGER PRIMARY KEY,
  name TEXT NOT NULL CHECK (length(trim(name)) BETWEEN 1 AND 60),
  parentId INTEGER REFERENCES Theme(id) ON DELETE RESTRICT,
  sheetMarkdown TEXT,
  sheetModel TEXT,
  sheetGeneratedAt TEXT,
  changesSinceSheet INTEGER NOT NULL DEFAULT 0,
  createdAt TEXT NOT NULL
);

CREATE TABLE IF NOT EXISTS ImportBatch (
  id INTEGER PRIMARY KEY,
  input TEXT NOT NULL,
  videoCount INTEGER NOT NULL DEFAULT 0,
  skippedCount INTEGER NOT NULL DEFAULT 0,
  createdAt TEXT NOT NULL
);

CREATE TABLE IF NOT EXISTS Video (
  id TEXT PRIMARY KEY CHECK (length(id) = 11),
  url TEXT NOT NULL,
  title TEXT,
  channel TEXT,
  channelId TEXT,
  durationS INTEGER,
  publishedAt TEXT,
  chapters TEXT,
  language TEXT,
  state TEXT NOT NULL DEFAULT 'queued'
    CHECK (state IN ('queued','fetching','summarizing','classifying','done','no_transcript','failed')),
  error TEXT,
  themeId INTEGER REFERENCES Theme(id) ON DELETE SET NULL,
  themeSource TEXT CHECK (themeSource IN ('auto','manual','proposed')),
  proposedTheme TEXT,
  classifyConfidence INTEGER CHECK (classifyConfidence BETWEEN 0 AND 1000),
  importBatchId INTEGER REFERENCES ImportBatch(id),
  createdAt TEXT NOT NULL,
  updatedAt TEXT NOT NULL
);
CREATE INDEX IF NOT EXISTS Video_theme ON Video(themeId);
CREATE INDEX IF NOT EXISTS Video_state ON Video(state);

CREATE TABLE IF NOT EXISTS Transcript (
  videoId TEXT PRIMARY KEY REFERENCES Video(id) ON DELETE CASCADE,
  language TEXT,
  kind TEXT NOT NULL CHECK (kind IN ('manual','auto')),
  text TEXT NOT NULL,
  chars INTEGER NOT NULL
);

CREATE TABLE IF NOT EXISTS Summary (
  videoId TEXT PRIMARY KEY REFERENCES Video(id) ON DELETE CASCADE,
  markdown TEXT NOT NULL,
  model TEXT NOT NULL,
  createdAt TEXT NOT NULL
);

CREATE TABLE IF NOT EXISTS Job (
  id INTEGER PRIMARY KEY,
  videoId TEXT NOT NULL REFERENCES Video(id) ON DELETE CASCADE,
  step TEXT NOT NULL CHECK (step IN ('fetch','summarize','classify')),
  state TEXT NOT NULL DEFAULT 'queued' CHECK (state IN ('queued','running','done','failed')),
  attempts INTEGER NOT NULL DEFAULT 0,
  runAfter TEXT NOT NULL,
  error TEXT,
  createdAt TEXT NOT NULL,
  updatedAt TEXT NOT NULL
);
CREATE INDEX IF NOT EXISTS Job_ready ON Job(state, runAfter);

CREATE TABLE IF NOT EXISTS ApiCall (
  id INTEGER PRIMARY KEY,
  provider TEXT NOT NULL,
  feature TEXT NOT NULL,
  model TEXT,
  videoId TEXT,
  themeId INTEGER,
  tokensIn INTEGER,
  tokensOut INTEGER,
  costMicrousd INTEGER NOT NULL CHECK (typeof(costMicrousd) = 'integer' AND costMicrousd >= 0),
  createdAt TEXT NOT NULL
);
CREATE INDEX IF NOT EXISTS ApiCall_video ON ApiCall(videoId);

CREATE TABLE IF NOT EXISTS Setting (
  key TEXT PRIMARY KEY,
  value TEXT NOT NULL
);

CREATE VIRTUAL TABLE IF NOT EXISTS SearchIndex USING fts5(
  videoId UNINDEXED, title, summary, transcript,
  tokenize = 'unicode61 remove_diacritics 2'
);
`;
```

`lib/db.mjs` :

```js
// One SQLite file is the whole library. The web app, the worker and the MCP server each open it;
// WAL lets the readers read while the worker writes.
import fs from "node:fs";
import path from "node:path";
import Database from "better-sqlite3";
import { SCHEMA, SCHEMA_VERSION } from "./schema.mjs";

export function dbPath() {
  return process.env.DATATUBE_DB?.trim() || path.join(process.cwd(), "data", "datatube.db");
}

export function migrate(db) {

  if (version >= SCHEMA_VERSION) return;
  db.exec(SCHEMA);
  db.pragma(`user_version = ${SCHEMA_VERSION}`);
}

  if (!inMemory && !readonly) fs.mkdirSync(path.dirname(file), { recursive: true });

  db.pragma("busy_timeout = 5000");
  db.pragma("foreign_keys = ON");
  if (!readonly) {
    if (!inMemory) db.pragma("journal_mode = WAL");
    migrate(db);
  }
  return db;
}
```

```js
// What Robin pastes: one link per line — a video, a playlist or a channel.
const ID = /^[A-Za-z0-9_-]{11}$/;
const YT_HOSTS = new Set(["youtube.com", "youtube-nocookie.com"]);

function toUrl(input) {
  const s = String(input ?? "").trim();
  if (!s) return null;
  try { return new URL(/^https?:\/\//i.test(s) ? s : `https://${s}`); } catch { return null; }
}
const hostOf = (url) => url.hostname.toLowerCase().replace(/^(www\.|m\.|music\.)/, "");

export const canonicalVideoUrl = (id) => `https://www.youtube.com/watch?v=${id}`;

export function videoIdOf(input) {
  const s = String(input ?? "").trim();
  if (ID.test(s)) return s;
  const url = toUrl(s);
  if (!url) return null;
  const host = hostOf(url);
  if (host === "youtu.be") {
    const id = url.pathname.slice(1, 12);
    return ID.test(id) ? id : null;
  }
  if (!YT_HOSTS.has(host)) return null;
  const v = url.searchParams.get("v");
  if (v) return ID.test(v) ? v : null;
  const m = url.pathname.match(/^\/(?:shorts|embed|live|v)\/([A-Za-z0-9_-]{11})(?:[/?]|$)/);
  return m ? m[1] : null;
}

export function classifyInput(line) {
  const input = String(line ?? "").trim();
  const videoId = videoIdOf(input);
  if (videoId) return { kind: "video", videoId, url: canonicalVideoUrl(videoId) };
  const url = toUrl(input);
  if (url && YT_HOSTS.has(hostOf(url))) {
    const list = url.searchParams.get("list");
    if (url.pathname === "/playlist" && list) {
      return { kind: "playlist", url: `https://www.youtube.com/playlist?list=${encodeURIComponent(list)}` };
    }
    const channel = url.pathname.match(/^\/(@[^/]+|channel\/[^/]+|c\/[^/]+|user\/[^/]+)/);
    if (channel) return { kind: "channel", url: `https://www.youtube.com/${channel[1]}/videos` };
  }
  return { kind: "invalid", input };
}

export function parseInput(text) {
  const seen = new Set();
  const out = [];
  for (const raw of String(text ?? "").split(/\r?\n/)) {
    const line = raw.trim();
    if (!line || line.startsWith("#") || seen.has(line)) continue;
    seen.add(line);
    out.push(classifyInput(line));
  }
  return out;
}
```

- **Correction :** ytquest formatait `HH:MM`, c'est-à-dire les heures et les minutes. Ici, on formate bien `MM:SS`.

```js
// [MM:SS] is the unit of evidence in every sheet: written here, read back here.
const pad = (n) => String(n).padStart(2, "0");

export function formatTimestamp(seconds) {
  const t = Math.max(0, Math.floor(Number(seconds) || 0));
  const h = Math.floor(t / 3600);
  const m = Math.floor((t % 3600) / 60);
  const s = t % 60;
  return h > 0 ? `${h}:${pad(m)}:${pad(s)}` : `${pad(m)}:${pad(s)}`;
}

export function parseTimestamp(text) {
  const m = String(text ?? "").trim().match(/^(?:(\d+):)?(\d+):(\d{2})(?:[.,]\d+)?$/);
  if (!m) return null;
  return Number(m[1] ?? 0) * 3600 + Number(m[2]) * 60 + Number(m[3]);
}

export function lineSeconds(line) {
  const m = String(line ?? "").match(/^\[(\d+(?::\d{2}){1,2})\]/);
  return m ? parseTimestamp(m[1]) : null;
}

export function linkTimestamps(markdown) {
  return String(markdown ?? "").replace(/\[(\d{1,3}:\d{2}(?::\d{2})?)\](?!\()/g, (match, stamp) => {
    const s = parseTimestamp(stamp);
    return s == null ? match : `[${stamp}](#t=${s})`;
  });
}
```

`lib/youtube/vtt.mjs` :

```js
// WebVTT → clean timestamped segments — the ytquest method (parse_vtt.py), in JS.
// YouTube's auto captions roll: the clean text is the first line of each one-frame cue
// (< 0.02 s). Manual subtitles have no such cue: every cue counts, its lines joined.
import { formatTimestamp } from "./timestamps.mjs";

const CUE = /^(\d{2,}):(\d{2}):(\d{2})\.(\d{3})\s+-->\s+(\d{2,}):(\d{2}):(\d{2})\.(\d{3})/;
const toSeconds = (h, m, s, ms) => Number(h) * 3600 + Number(m) * 60 + Number(s) + Number(ms) / 1000;

function clean(text) {
  return text
    .replace(/<[^>]+>/g, "")
    .replace(/&nbsp;/g, " ").replace(/&lt;/g, "<").replace(/&gt;/g, ">")
    .replace(/&quot;/g, '"').replace(/&#39;/g, "'").replace(/&amp;/g, "&")
    .replace(/\s+/g, " ")
    .trim();
}

function cues(vtt) {
  const out = [];
  let current = null;
  for (const raw of String(vtt ?? "").split("\n")) {
    const line = raw.replace(/\r$/, "");
    const m = line.match(CUE);
    if (m) {
      current = { start: toSeconds(m[1], m[2], m[3], m[4]), end: toSeconds(m[5], m[6], m[7], m[8]), lines: [] };
      out.push(current);
    } else if (line === "") {
      current = null; // a truly empty line ends a cue; a line holding one space is inside it
    } else if (current) {
      current.lines.push(line);
    }
  }
  return out;
}

export function parseVtt(vtt) {
  const all = cues(vtt);
  const rolling = all.some((c) => c.end - c.start < 0.02);
  const segments = [];
  for (const cue of all) {
    let text;
    if (rolling) {
      if (cue.end - cue.start >= 0.02) continue;
      text = clean(cue.lines.find((l) => l.trim()) ?? "");
    } else {
      text = clean(cue.lines.join(" "));
    }
    if (!text || segments.at(-1)?.text === text) continue;
    segments.push({ startS: Math.floor(cue.start), text });
  }
  return segments;
}

export function transcriptText(segments) {
  return segments.map((s) => `[${formatTimestamp(s.startS)}] ${s.text}`).join("\n");
}
```

```js
// From Robin's home IP no cookie is needed; `deno` must be installed (yt-dlp solves YouTube's
// JS challenges with it). The process runner is always injected: tests never spawn yt-dlp.
import { execFile } from "node:child_process";
import fs from "node:fs/promises";
import os from "node:os";
import path from "node:path";
import { canonicalVideoUrl, videoIdOf } from "./urls.mjs";

export class YtDlpError extends Error {
  constructor(message, { rateLimited = false, unavailable = false, missing = false } = {}) {
    super(message);
    this.name = "YtDlpError";
    this.rateLimited = rateLimited;
    this.unavailable = unavailable;
    this.missing = missing;
  }
}

export function classifyError(err, stderr = "") {
  if (err?.code === "ENOENT") {
    return new YtDlpError("yt-dlp is not installed — run: brew install yt-dlp deno", { missing: true });
  }
  const text = `${stderr}\n${err?.message ?? ""}`;
  const lines = text.split("\n").map((l) => l.trim()).filter(Boolean);
  const message = (lines.filter((l) => l.startsWith("ERROR:")).at(-1) ?? lines.at(-1) ?? "yt-dlp failed").slice(0, 500);
  return new YtDlpError(message, {
    rateLimited: /HTTP Error 429|Too Many Requests/i.test(text),
    unavailable: /Video unavailable|Private video|has been removed|members-only|confirm your age/i.test(text),
  });
}

export function runYtDlp(args, { bin = process.env.YTDLP_BIN?.trim() || "yt-dlp", timeoutMs = 180_000 } = {}) {
  return new Promise((resolve, reject) => {
    execFile(bin, args, { maxBuffer: 256 * 1024 * 1024, timeout: timeoutMs }, (err, stdout, stderr) => {
      if (err) reject(classifyError(err, String(stderr ?? "")));
      else resolve(String(stdout));
    });
  });
}

const HIDDEN = /^\[(Private|Deleted) video\]$/;

export function entriesOf(json) {
  const out = [];
  const walk = (node) => {
    if (!node || typeof node !== "object") return;
    if (Array.isArray(node.entries)) { node.entries.forEach(walk); return; }
    if (node.ie_key && node.ie_key !== "Youtube") return;
    const id = videoIdOf(node.id ?? "") ?? videoIdOf(node.url ?? "");
    const title = typeof node.title === "string" ? node.title : null;
    if (id && !(title && HIDDEN.test(title))) out.push({ videoId: id, title });
  };
  walk(json);
  return out;
}

export async function listEntries(url, { run }) {

export function metadataOf(json) {
  const date = str(json?.upload_date)?.match(/^(\d{4})(\d{2})(\d{2})$/);
  return {
    videoId: json?.id ?? null,
    title: str(json?.title),
    channel: str(json?.channel) ?? str(json?.uploader),
    channelId: str(json?.channel_id),
    durationS: Number.isFinite(json?.duration) ? Math.round(json.duration) : null,
    publishedAt: date ? `${date[1]}-${date[2]}-${date[3]}` : null,
    chapters: Array.isArray(json?.chapters)
      ? json.chapters.filter((c) => Number.isFinite(c?.start_time)).map((c) => ({ startS: Math.floor(c.start_time), title: str(c.title) ?? "" }))
      : [],
    language: str(json?.language),
    subtitles: Object.keys(json?.subtitles ?? {}).filter((k) => k !== "live_chat"),
    automaticCaptions: Object.keys(json?.automatic_captions ?? {}),
  };
}

export async function fetchMetadata(videoId, { run }) {
  return metadataOf(JSON.parse(await run(["-J", "--skip-download", "--no-warnings", canonicalVideoUrl(videoId)])));

const base = (code) => String(code).split("-")[0].toLowerCase();

// The spoken words first: manual then auto in the original language; French or English manual
// subtitles next; French/English auto only when the original language is unknown (otherwise
// they are machine translations of the spoken words).
export function trackCandidates(meta) {
  const manual = meta?.subtitles ?? [];
  const auto = meta?.automaticCaptions ?? [];
  const origAuto = auto.find((k) => k.endsWith("-orig")) ?? null;
  const orig = meta?.language ? base(meta.language) : origAuto ? base(origAuto) : null;
  const out = [];
  const add = (lang, kind) => {
    if (lang && !out.some((t) => t.lang === lang && t.kind === kind)) out.push({ lang, kind });
  };
  const manualIn = (l) => manual.find((k) => k.toLowerCase() === l) ?? manual.find((k) => base(k) === l);
  const autoIn = (l) => auto.find((k) => k === `${l}-orig`) ?? auto.find((k) => k.toLowerCase() === l);
  if (orig) {
    add(manualIn(orig), "manual");
    add(autoIn(orig), "auto");
  }
  add(manualIn("fr"), "manual");
  add(manualIn("en"), "manual");
  if (!orig) {
    add(autoIn("fr"), "auto");
    add(autoIn("en"), "auto");
  }
  add(manual[0], "manual");
  add(origAuto, "auto");
  return out;
}

const escapeRegex = (s) => s.replace(/[.*+?^${}()|[\]\\]/g, "\\$&");

export async function downloadSubtitle(videoId, track, { run }) {
  const dir = await fs.mkdtemp(path.join(os.tmpdir(), "datatube-"));
  try {
    await run([
      "--skip-download",
      track.kind === "manual" ? "--write-subs" : "--write-auto-subs",
      "--sub-langs", `^${escapeRegex(track.lang)}$`,
      "--sub-format", "vtt",
      "--no-warnings",
      "-o", path.join(dir, "%(id)s.%(ext)s"),
      canonicalVideoUrl(videoId),
    ]);
    const files = (await fs.readdir(dir)).filter((f) => f.endsWith(".vtt"));
    const file = files.find((f) => f.endsWith(`.${track.lang}.vtt`)) ?? files[0];
    return file ? await fs.readFile(path.join(dir, file), "utf8") : null;
  } finally {
    await fs.rm(dir, { recursive: true, force: true });
  }
}

const execVersion = (bin) => new Promise((resolve, reject) => {
  execFile(bin, ["--version"], { timeout: 10_000 }, (err, stdout) => (err ? reject(err) : resolve(String(stdout))));
});

export async function checkTools({ exec = execVersion } = {}) {
  const version = async (bin) => {
    try { return (await exec(bin)).split("\n")[0].trim() || null; } catch { return null; }
  };
  return { ytDlp: await version(process.env.YTDLP_BIN?.trim() || "yt-dlp"), deno: await version("deno") };
}
```

```js
// What a call costs, in integer micro-USD. Rates are micro-USD per MILLION tokens, so
// tokens × rate / 1 000 000 is micro-USD. BigInt all along; one rounding (half-up), of the total.
// DeepSeek grid of 2026-09-16, TypeSafe Jev input-only — as Dewex OS bills them.
const RATES = {
  "deepseek-v4-flash": {
    peak: { miss: 300_000n, hit: 6_000n, out: 1_200_000n },
    offPeak: { miss: 150_000n, hit: 3_000n, out: 600_000n },
  },
  "jev-1.13.0": { flat: { miss: 42_000n, hit: 42_000n, out: 0n } },
};

export function isDeepseekPeak(at) {
  const day = at.getUTCDay();
  const hour = at.getUTCHours();
  return day >= 1 && day <= 5 && ((hour >= 1 && hour < 4) || (hour >= 6 && hour < 10));
}

function ratesFor(model, at) {
  const entry = RATES[model];
  if (!entry) throw new Error(`No price for model "${model}"`);
  if (entry.flat) return entry.flat;
  return isDeepseekPeak(at) ? entry.peak : entry.offPeak;
}

export function costMicrousd(model, { missTokens = 0, hitTokens = 0, outTokens = 0 }, at) {
  const r = ratesFor(model, at);
  const total = BigInt(missTokens) * r.miss + BigInt(hitTokens) * r.hit + BigInt(outTokens) * r.out;
  return Number((total + 500_000n) / 1_000_000n);
}
```

```js
export function recordApiCall(db, { provider, feature, model = null, videoId = null, themeId = null, tokensIn = null, tokensOut = null, costMicrousd, at }) {
  if (!Number.isSafeInteger(costMicrousd) || costMicrousd < 0) throw new Error("costMicrousd must be a non-negative integer");
  db.prepare(`INSERT INTO ApiCall (provider, feature, model, videoId, themeId, tokensIn, tokensOut, costMicrousd, createdAt)
              VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?)`)

}

export function costTotals(db, { sinceIso }) {
  const row = db.prepare(`SELECT COALESCE(SUM(costMicrousd), 0) AS allMicrousd,
                                 COALESCE(SUM(CASE WHEN createdAt >= ? THEN costMicrousd END), 0) AS sinceMicrousd
                          FROM ApiCall`).get(sinceIso);
  return { allMicrousd: row.allMicrousd, sinceMicrousd: row.sinceMicrousd };
}

// Truncated, never rounded up: a spend is never shown larger than it was.
export function formatUsd(micro) {
  if (micro === null || micro === undefined) return "—";
  const m = BigInt(micro);
  const cents = m / 10_000n;
  if (m > 0n && cents === 0n) return "< $0.01";
  return `$${cents / 100n}.${String(cents % 100n).padStart(2, "0")}`;
}
```

```js
// DeepSeek writes: the video sheets, the theme sheets, the name of a new theme.
import { LlmError } from "./errors.mjs";
import { costMicrousd } from "./prices.mjs";

const ENDPOINT = "https://api.deepseek.com/chat/completions";
const RETRIES = 3;

export function createDeepseek({
  apiKey = process.env.DEEPSEEK_API_KEY,
  fetchImpl = (...args) => globalThis.fetch(...args),
  now = () => new Date(),
  sleep = (ms) => new Promise((r) => setTimeout(r, ms)),
  record,
} = {}) {
  return async function complete({ model, system, user, json = false, maxTokens = 8000, feature, videoId = null, themeId = null, timeoutMs = 300_000 }) {
    if (!apiKey?.trim()) throw new LlmError("DEEPSEEK_API_KEY is missing in .env.local", "no_key");
    const body = JSON.stringify({
      model,
      temperature: 0.2,
      max_tokens: maxTokens,
      // V4 thinks by default and its reasoning eats max_tokens: every task here is direct writing.
      thinking: { type: "disabled" },
      messages: [{ role: "system", content: system }, { role: "user", content: user }],
      ...(json ? { response_format: { type: "json_object" } } : {}),
    });
    for (let attempt = 0; ; attempt++) {
      let res;
      try {
        res = await fetchImpl(ENDPOINT, {
          method: "POST",
          headers: { Authorization: `Bearer ${apiKey.trim()}`, "Content-Type": "application/json" },
          body,
          signal: AbortSignal.timeout(timeoutMs),
        });
      } catch (err) {
        if (attempt < RETRIES) { await sleep(1000 * 2 ** attempt); continue; }
        throw new LlmError(`DeepSeek unreachable: ${err?.message ?? err}`, "network");
      }
      if (res.status === 429 || res.status >= 500) {
        if (attempt < RETRIES) { await sleep(1000 * 2 ** attempt); continue; }
        throw new LlmError(`DeepSeek answered ${res.status}`, "unavailable");
      }
      const data = await res.json().catch(() => null);
      if (!res.ok) throw new LlmError(`DeepSeek refused the request (${res.status}): ${JSON.stringify(data?.error ?? data).slice(0, 300)}`, "bad_request");
      const u = data?.usage ?? {};
      const hit = u.prompt_cache_hit_tokens ?? 0;
      const miss = u.prompt_cache_miss_tokens ?? Math.max(0, (u.prompt_tokens ?? 0) - hit);
      const usage = { missTokens: miss, hitTokens: hit, outTokens: u.completion_tokens ?? 0 };
      // The money is spent even when the answer is unusable: record first.
      record({ provider: "deepseek", feature, model, videoId, themeId, tokensIn: miss + hit, tokensOut: usage.outTokens, costMicrousd: costMicrousd(model, usage, now()) });
      const choice = data?.choices?.[0];
      if (choice?.finish_reason === "length") throw new LlmError(`DeepSeek's answer was cut at ${maxTokens} tokens`, "truncated");
      const text = choice?.message?.content ?? "";
      if (!text.trim()) throw new LlmError("DeepSeek returned an empty answer", "empty");
      return { text, usage };
    }
  };
}
```

```js
// Jev (TypeSafe System One) classifies: it never writes text, it returns calibrated answers.
import { LlmError } from "./errors.mjs";
import { JEV_MODEL } from "./models.mjs";
import { costMicrousd } from "./prices.mjs";

const ENDPOINT = "https://api.typesafe.ai/v1/systemone";
const RETRIES = 3;
const MAX_WAIT_MS = 20_000;

export function createJev({
  apiKey = process.env.TYPESAFE_API_KEY,
  fetchImpl = (...args) => globalThis.fetch(...args),
  now = () => new Date(),
  sleep = (ms) => new Promise((r) => setTimeout(r, ms)),
  record,
} = {}) {
  return async function ask({ state, questions, feature, videoId = null, model = JEV_MODEL, timeoutMs = 60_000 }) {
    if (!apiKey?.trim()) throw new LlmError("TYPESAFE_API_KEY is missing in .env.local", "no_key");
    const body = JSON.stringify({ model, state, questions });
    for (let attempt = 0; ; attempt++) {
      let res;
      try {
        res = await fetchImpl(ENDPOINT, {
          method: "POST",
          headers: { Authorization: `Bearer ${apiKey.trim()}`, "Content-Type": "application/json" },
          body,
          signal: AbortSignal.timeout(timeoutMs),
        });
      } catch (err) {
        if (attempt < RETRIES) { await sleep(1000 * 2 ** attempt); continue; }
        throw new LlmError(`Jev unreachable: ${err?.message ?? err}`, "network");
      }
      if (res.status === 429 || res.status >= 500) {
        if (attempt < RETRIES) {
          const header = Number(res.headers?.get?.("retry-after"));
          await sleep(Number.isFinite(header) && header > 0 ? Math.min(header * 1000, MAX_WAIT_MS) : 1000 * 2 ** attempt);
          continue;
        }
        throw new LlmError(`Jev answered ${res.status}`, "unavailable");
      }
      const text = await res.text();
      if (!res.ok) throw new LlmError(`Jev refused the request (${res.status}): ${text.slice(0, 300)}`, "bad_request");
      let out;
      try { out = JSON.parse(text); } catch { throw new LlmError("Jev returned something that is not JSON", "bad_response"); }
      if (!out?.answers || typeof out.answers !== "object") throw new LlmError("Jev returned no answers", "bad_response");
      const tokensIn = out.usage?.input_tokens ?? 0;
      const tokensOut = out.usage?.output_tokens ?? 0;
      const usedModel = out.model ?? model;
      record({ provider: "typesafe", feature, model: usedModel, videoId, themeId: null, tokensIn, tokensOut, costMicrousd: costMicrousd(usedModel, { missTokens: tokensIn, outTokens: tokensOut }, now()) });
      return out.answers;
    }
  };
}

export function choiceOf(answers, id) {
  const a = answers?.[id];
  if (a?.type !== "choice" || typeof a.choice !== "string") return null;
  const probabilities = a.probabilities && typeof a.probabilities === "object" ? a.probabilities : {};
  const confidence = Number.isFinite(Number(a.confidence)) ? Number(a.confidence) : null;
  return { choice: a.choice, p: Number(probabilities[a.choice]) || 0, confidence, probabilities };
}
```

```js
import { LlmError } from "../llm/errors.mjs";
import { formatTimestamp } from "../youtube/timestamps.mjs";
import { SUMMARY_SECTIONS } from "./prompts.mjs";

export function sheetHeader(video) {
  const meta = [
    `**Channel:** ${video.channel ?? "—"}`,
    `**Duration:** ${video.durationS != null ? formatTimestamp(video.durationS) : "—"}`,
    `**Language:** ${video.language ?? "—"}`,
    `**Published:** ${video.publishedAt ?? "—"}`,
    `**Link:** https://www.youtube.com/watch?v=${video.id}`,
  ].join(" · ");
  return `# ${video.title ?? video.id}\n${meta}`;
}

export function bodyFrom(text, firstHeading) {
  const s = String(text ?? "");
  const i = s.indexOf(firstHeading);
  return (i < 0 ? s : s.slice(i)).trim();
}

export function assertSections(text, headings, what) {
  const missing = headings.filter((h) => !text.includes(h));
  if (missing.length) throw new LlmError(`${what} is missing: ${missing.join(", ")}`, "bad_format");
}

export function sectionText(markdown, heading) {
  const s = String(markdown ?? "");
  const start = s.indexOf(heading);
  if (start < 0) return "";
  const rest = s.slice(start + heading.length);
  const next = rest.search(/\n## /);
  return (next < 0 ? rest : rest.slice(0, next)).trim();
}

export function summaryBody(markdown) {
  return bodyFrom(markdown, SUMMARY_SECTIONS[0]);
}

export function parseChapters(json) {
  try {
    const list = JSON.parse(json ?? "[]");
    return Array.isArray(list) ? list.filter((c) => Number.isFinite(c?.startS)) : [];
  } catch {
    return [];
  }
}
```

```js
// One video → one knowledge sheet. Past 50K characters the transcript is read in 40K parts
// overlapping by 2K (the ytquest method): notes per part, then one merge into the sheet.
import { formatTimestamp, lineSeconds } from "../youtube/timestamps.mjs";
import { NOTES_SYSTEM, SUMMARY_SECTIONS, SUMMARY_SYSTEM, mergeUser, notesUser, summaryUser } from "./prompts.mjs";
import { assertSections, bodyFrom, parseChapters, sheetHeader } from "./markdown.mjs";

export const CHUNK_THRESHOLD = 50_000;
export const CHUNK_SIZE = 40_000;
export const CHUNK_OVERLAP = 2_000;

const stampOf = (line) => {
  const s = lineSeconds(line);
  return s == null ? "?" : formatTimestamp(s);
};

export function chunkTranscript(text, { size = CHUNK_SIZE, overlap = CHUNK_OVERLAP } = {}) {
  const lines = String(text ?? "").split("\n");
  const parts = [];
  let start = 0;
  while (start < lines.length) {
    let end = start;
    let length = 0;
    while (end < lines.length && (end === start || length + lines[end].length + 1 <= size)) {
      length += lines[end].length + 1;
      end++;
    }
    parts.push(lines.slice(start, end));
    if (end >= lines.length) break;
    // Step back so the next part re-reads up to `overlap` characters — never to `start` itself.
    let back = end;
    let backLength = 0;
    while (back > start + 1 && backLength + lines[back - 1].length + 1 <= overlap) {
      back--;
      backLength += lines[back].length + 1;
    }
    start = back;
  }
  return parts.map((ls) => ({ text: ls.join("\n"), from: stampOf(ls[0]), to: stampOf(ls.at(-1)) }));
}

export async function summarizeVideo({ video, transcript, model, complete }) {
  const chapters = parseChapters(video.chapters);
  let answer;
  if (transcript.length <= CHUNK_THRESHOLD) {
    answer = await complete({ model, system: SUMMARY_SYSTEM, user: summaryUser(video, transcript, chapters), feature: "summary" });
  } else {
    const chunks = chunkTranscript(transcript);
    const notes = [];
    for (const [i, chunk] of chunks.entries()) {
      const part = await complete({ model, system: NOTES_SYSTEM, user: notesUser(video, chunk, i, chunks.length), feature: "summary_notes" });
      notes.push(part.text.trim());
    }
    answer = await complete({ model, system: SUMMARY_SYSTEM, user: mergeUser(video, notes, chapters), feature: "summary_merge" });
  }
  const body = bodyFrom(answer.text, SUMMARY_SECTIONS[0]);
  assertSections(body, SUMMARY_SECTIONS, "The summary");
  return `${sheetHeader(video)}\n\n${body}\n`;
}
```

```js
// Themes: two levels at most (Parent › Child). A theme's sheet goes stale by one each time a
// video enters or leaves it (changesSinceSheet).
import { iso } from "./time.mjs";

export function themePath(theme, byId) {
  const parent = theme?.parentId ? byId.get(theme.parentId) : null;
  return parent ? `${parent.name} › ${theme.name}` : theme.name;
}

export const listThemes = (db) => db.prepare("SELECT * FROM Theme ORDER BY name COLLATE NOCASE").all();
export const themesById = (db) => new Map(listThemes(db).map((t) => [t.id, t]));

export function findThemeByPath(db, name, parentName = null) {
  if (parentName) {
    return db.prepare(`SELECT t.* FROM Theme t JOIN Theme p ON p.id = t.parentId
                       WHERE t.name = ? COLLATE NOCASE AND p.name = ? COLLATE NOCASE AND p.parentId IS NULL`).get(name.trim(), parentName.trim()) ?? null;
  }
  return db.prepare("SELECT * FROM Theme WHERE name = ? COLLATE NOCASE AND parentId IS NULL").get(name.trim()) ?? null;
}

function insertTheme(db, name, parentId, now) {
  const id = db.prepare("INSERT INTO Theme (name, parentId, changesSinceSheet, createdAt) VALUES (?, ?, 0, ?)").run(name.trim(), parentId, iso(now)).lastInsertRowid;
  return db.prepare("SELECT * FROM Theme WHERE id = ?").get(id);
}

export function findOrCreateTheme(db, { name, parent = null }, now) {
  return db.transaction(() => {
    const existing = findThemeByPath(db, name, parent);
    if (existing) return existing;
    const parentTheme = parent ? (findThemeByPath(db, parent) ?? insertTheme(db, parent, null, now)) : null;
    return insertTheme(db, name, parentTheme?.id ?? null, now);
  })();
}

export function assignVideo(db, videoId, themeId, source, now) {
  db.transaction(() => {
    const video = db.prepare("SELECT themeId FROM Video WHERE id = ?").get(videoId);
    if (!video) throw new Error("Unknown video.");
    const bump = db.prepare("UPDATE Theme SET changesSinceSheet = changesSinceSheet + 1 WHERE id = ?");
    if (video.themeId !== themeId) {
      if (video.themeId) bump.run(video.themeId);
      if (themeId) bump.run(themeId);
    }
    db.prepare("UPDATE Video SET themeId = ?, themeSource = ?, proposedTheme = NULL, updatedAt = ? WHERE id = ?")
      .run(themeId, themeId ? source : null, iso(now), videoId);
  })();
}

export function acceptProposal(db, videoId, { name, parent = null }, now) {
  const theme = findOrCreateTheme(db, { name, parent }, now);
  assignVideo(db, videoId, theme.id, "manual", now);
  return theme;
}

export function renameTheme(db, themeId, name) {
  const theme = db.prepare("SELECT * FROM Theme WHERE id = ?").get(themeId);
  if (!theme) throw new Error("Unknown theme.");
  const clash = db.prepare("SELECT 1 FROM Theme WHERE name = ? COLLATE NOCASE AND parentId IS ? AND id != ?").get(name.trim(), theme.parentId, themeId);
  if (clash) throw new Error("A theme with this name already exists here.");
  db.prepare("UPDATE Theme SET name = ? WHERE id = ?").run(name.trim(), themeId);
}

export function setThemeParent(db, themeId, parentId) {
  if (parentId === themeId) throw new Error("A theme cannot be its own parent.");
  const hasChildren = db.prepare("SELECT 1 FROM Theme WHERE parentId = ?").get(themeId);
  if (parentId != null) {
    const parent = db.prepare("SELECT * FROM Theme WHERE id = ?").get(parentId);
    if (!parent) throw new Error("Unknown parent theme.");
    if (parent.parentId != null || hasChildren) throw new Error("Themes have two levels at most.");
  }
  db.prepare("UPDATE Theme SET parentId = ? WHERE id = ?").run(parentId, themeId);
}

export function deleteTheme(db, themeId) {
  if (db.prepare("SELECT 1 FROM Theme WHERE parentId = ?").get(themeId)) throw new Error("Move or delete its sub-themes first.");
  if (db.prepare("SELECT 1 FROM Video WHERE themeId = ?").get(themeId)) throw new Error("Move its videos first.");
  db.prepare("DELETE FROM Theme WHERE id = ?").run(themeId);
}

export function recentTitlesByTheme(db, perTheme = 3) {
  const rows = db.prepare("SELECT themeId, title FROM Video WHERE themeId IS NOT NULL AND title IS NOT NULL ORDER BY updatedAt DESC").all();
  const out = new Map();
  for (const r of rows) {
    const list = out.get(r.themeId) ?? [];
    if (list.length < perTheme) list.push(r.title);
    out.set(r.themeId, list);
  }
  return out;
}
```

```js
// Jev picks a theme among the existing ones, with a calibrated probability; under the threshold,
// or when « none » wins, DeepSeek proposes a name and the video waits in Review.
import { z } from "zod";
import { LlmError } from "../llm/errors.mjs";
import { choiceOf } from "../llm/jev.mjs";
import { iso } from "../time.mjs";
import { assignVideo, findThemeByPath, listThemes, recentTitlesByTheme, themePath } from "../themes.mjs";
import { sectionText } from "./markdown.mjs";
import { PROPOSAL_SYSTEM, proposalUser } from "./prompts.mjs";

const STATE_CHARS = 6000;

export function classifyState(video, summary) {
  const excerpt = [sectionText(summary, "## 🎯 Core idea"), sectionText(summary, "## 💡 Key points")]
    .filter(Boolean).join("\n\n").slice(0, STATE_CHARS);
  return { video: { title: video.title ?? null, channel: video.channel ?? null }, summary: excerpt };
}

export function buildThemeQuestion(themes, samples = new Map()) {
  const byId = new Map(themes.map((t) => [t.id, t]));
  const criteria = {};
  for (const t of themes) {
    const titles = (samples.get(t.id) ?? []).map((s) => `"${s}"`).join("; ");
    criteria[`t${t.id}`] = `The theme "${themePath(t, byId)}".${titles ? ` Videos already in it: ${titles}.` : ""}`;
  }
  criteria.none = "None of the themes above fits the main subject of the video.";
  return {
    theme: {
      type: "choice",
      instructions: "Which theme best matches the main subject of `video`, judging by its `title`, `channel` and `summary`?",
      criteria,
    },
  };
}

export function decideTheme(answer, { thresholdPermille }) {
  if (!answer) return { themeId: null, confidencePermille: null };
  const p = answer.p || (Number.isFinite(answer.confidence) ? answer.confidence : 0);
  const confidencePermille = Math.max(0, Math.min(1000, Math.round(p * 1000)));
  const match = /^t(\d+)$/.exec(answer.choice ?? "");
  if (!match || confidencePermille < thresholdPermille) return { themeId: null, confidencePermille };
  return { themeId: Number(match[1]), confidencePermille };
}

const Proposal = z.object({
  name: z.string().trim().min(1).max(60),
  parent: z.string().trim().min(1).max(60).nullable().optional(),
});

export function parseProposal(text) {
  let json;
  try { json = JSON.parse(text); } catch { throw new LlmError("The theme proposal was not JSON", "bad_format"); }
  const parsed = Proposal.safeParse(json);
  if (!parsed.success) throw new LlmError("The theme proposal has no usable name", "bad_format");
  const { name, parent } = parsed.data;
  return { name, parent: parent && parent.toLowerCase() !== name.toLowerCase() ? parent : null };
}

export async function classifyVideo({ db, video, summary, model, thresholdPermille, jev, complete }) {
  const themes = listThemes(db);
  const byId = new Map(themes.map((t) => [t.id, t]));
  const state = classifyState(video, summary);
  let confidencePermille = null;
  if (themes.length) {
    const answers = await jev({ state, questions: buildThemeQuestion(themes, recentTitlesByTheme(db)), feature: "classify" });
    const decision = decideTheme(choiceOf(answers, "theme"), { thresholdPermille });
    if (decision.themeId && byId.has(decision.themeId)) {
      return { kind: "auto", themeId: decision.themeId, confidencePermille: decision.confidencePermille };
    }
    confidencePermille = decision.confidencePermille;
  }
  const { text } = await complete({
    model, system: PROPOSAL_SYSTEM, json: true, maxTokens: 200, feature: "theme_proposal",
    user: proposalUser(video, state.summary, themes.map((t) => themePath(t, byId))),
  });
  const proposal = parseProposal(text);
  const existing = findThemeByPath(db, proposal.name, proposal.parent);
  if (existing) return { kind: "auto", themeId: existing.id, confidencePermille };
  return { kind: "proposed", proposal, confidencePermille };
}

export function applyClassification(db, videoId, result, now) {
  if (result.kind === "auto") {
    assignVideo(db, videoId, result.themeId, "auto", now);
    db.prepare("UPDATE Video SET classifyConfidence = ? WHERE id = ?").run(result.confidencePermille, videoId);
    return;
  }
  db.transaction(() => {
    assignVideo(db, videoId, null, null, now);
    db.prepare("UPDATE Video SET themeSource = 'proposed', proposedTheme = ?, classifyConfidence = ?, updatedAt = ? WHERE id = ?")
      .run(JSON.stringify(result.proposal), result.confidencePermille, iso(now), videoId);
  })();
}
```

```js
// One theme → one consolidated sheet, from the sheets of the videos filed directly in it.
// Regenerated on demand only (a click), so its cost stays Robin's choice.
import { iso } from "../time.mjs";
import { assertSections, bodyFrom, summaryBody } from "./markdown.mjs";
import { THEME_SECTIONS, THEME_SYSTEM, themeUser } from "./prompts.mjs";

export const THEME_BATCH_CHARS = 60_000;
const MAX_DEPTH = 3;

export function packBlocks(blocks, limit = THEME_BATCH_CHARS) {
  const packs = [];
  let current = [];
  let size = 0;
  for (const block of blocks) {
    if (current.length && size + block.length > limit) {
      packs.push(current);
      current = [];
      size = 0;
    }
    current.push(block);
    size += block.length;
  }
  if (current.length) packs.push(current);
  return packs;
}

export async function buildThemeSheet({ path, videos, model, complete, themeId = null }) {
  const usable = videos.filter((v) => v.summary);
  if (!usable.length) throw new Error("This theme has no summarized video yet.");
  const ask = async (blocks, feature) => {
    const { text } = await complete({ model, system: THEME_SYSTEM, user: themeUser(path, blocks), feature, themeId, maxTokens: 8000 });
    return bodyFrom(text, THEME_SECTIONS[0]);
  };
  const merge = async (blocks, depth) => {
    const packs = packBlocks(blocks);
    if (packs.length === 1 || depth >= MAX_DEPTH) return ask(blocks, "theme_sheet");
    const partials = [];
    for (const pack of packs) partials.push(await ask(pack, "theme_sheet_part"));
    return merge(partials, depth + 1);
  };
  const body = await merge(usable.map((v) => `### ${v.title ?? v.id}\n${summaryBody(v.summary)}`), 1);
  assertSections(body, THEME_SECTIONS, "The theme sheet");
  const sources = usable
    .map((v) => `- [${v.title ?? v.id}](https://www.youtube.com/watch?v=${v.id}) — ${v.channel ?? "unknown channel"}`)
    .join("\n");
  return `# ${path}\n\n${body}\n\n## 📚 Sources\n${sources}\n`;
}

export function saveThemeSheet(db, themeId, markdown, model, now) {
  db.prepare("UPDATE Theme SET sheetMarkdown = ?, sheetModel = ?, sheetGeneratedAt = ?, changesSinceSheet = 0 WHERE id = ?")
    .run(markdown, model, iso(now), themeId);
}
```

```js
// Markdown files to hand to an AI: every file says where its knowledge comes from.
import { formatTimestamp } from "./youtube/timestamps.mjs";

export function slug(text) {
  return String(text ?? "")
    .normalize("NFKD").replace(/[̀-ͯ]/g, "")
    .toLowerCase().replace(/[^a-z0-9]+/g, "-").replace(/^-+|-+$/g, "")
    .slice(0, 60) || "untitled";
}

export function frontMatter(fields) {
  const lines = Object.entries(fields)
    .filter(([, v]) => v !== null && v !== undefined && v !== "")
    .map(([k, v]) => `${k}: ${typeof v === "number" ? v : JSON.stringify(String(v))}`);
  return `---\n${lines.join("\n")}\n---\n`;
}

const watchUrl = (id) => `https://www.youtube.com/watch?v=${id}`;

export function videoSheetFile({ video, summary, themePath, model }) {
  return {
    filename: `${slug(video.title)}-${video.id}.md`,
    content: `${frontMatter({
      source: watchUrl(video.id),
      title: video.title,
      channel: video.channel,
      published: video.publishedAt,
      duration: video.durationS != null ? formatTimestamp(video.durationS) : null,
      language: video.language,
      theme: themePath,
      generated_by: `DataTube · ${model}`,
    })}\n${summary}`,
  };
}

export function themeSheetFile({ path, sheetMarkdown, model, generatedAt, videoCount }) {
  return {
    filename: `${slug(path)}.md`,
    content: `${frontMatter({ theme: path, videos: videoCount, generated_at: generatedAt, generated_by: `DataTube · ${model}` })}\n${sheetMarkdown}`,
  };
}

export function themeBundleFile({ path, sheetMarkdown, model, generatedAt, videos }) {
  const head = frontMatter({ theme: path, videos: videos.length, generated_at: generatedAt, generated_by: `DataTube · ${model}` });
  const sheet = sheetMarkdown ?? `# ${path}\n\nNo consolidated sheet yet — regenerate it in DataTube.\n`;
  const parts = videos.map(({ video, summary }) => `\n\n---\n\n<!-- source: ${watchUrl(video.id)} -->\n${summary}`);
  return { filename: `${slug(path)}-bundle.md`, content: `${head}\n${sheet}${parts.join("")}\n` };
}
```

- **Priorité :** on finit une vidéo avant d'en commencer une autre (classify, puis summarize, puis fetch), puis `runAfter`, puis `id`.
- **Reprises :** 3 essais au total (tout de suite, +30 s, +2 min), puis `failed`. Une erreur finale ne se retente pas : clé manquante, requête refusée, vidéo indisponible, yt-dlp absent.
- **Limitation de YouTube :** un 429 de YouTube sur un fetch ne compte pas comme un essai. Toute la file des fetch se met en pause 10 min (`queuePausedUntil` en Setting), pendant que les résumés et les classements continuent.
- **Au démarrage :** un job resté `running` (worker tué) repasse `queued`.
- **Rythme :** 3 s au moins entre deux appels YouTube.
- **Statut de la vidéo :** `Video.state` suit l'étape en cours ou à venir, soit `queued` → `fetching` → `summarizing` → `classifying` → `done`.

```js
// The work queue, in SQLite. Only the worker claims; the web app only enqueues.
import { iso } from "./time.mjs";
import { setSetting } from "./settings.mjs";

export const RETRY_DELAYS_MS = Object.freeze([30_000, 120_000]);
export const YOUTUBE_PAUSE_MS = 10 * 60_000;

export function enqueue(db, { videoId, step, now, runAfter = now }) {
  const at = iso(now);
  return Number(db.prepare("INSERT INTO Job (videoId, step, state, attempts, runAfter, createdAt, updatedAt) VALUES (?, ?, 'queued', 0, ?, ?, ?)")
    .run(videoId, step, iso(runAfter), at, at).lastInsertRowid);
}

// One statement: the job is taken and marked in the same transaction.
export function claimNext(db, now) {
  return db.prepare(`
    UPDATE Job SET state = 'running', attempts = attempts + 1, updatedAt = @at
    WHERE id = (
      SELECT id FROM Job WHERE state = 'queued' AND runAfter <= @at
      ORDER BY CASE step WHEN 'classify' THEN 0 WHEN 'summarize' THEN 1 ELSE 2 END, runAfter, id
      LIMIT 1
    )
    RETURNING *`).get({ at: iso(now) }) ?? null;
}

export function completeJob(db, jobId, now) {
  db.prepare("UPDATE Job SET state = 'done', error = NULL, updatedAt = ? WHERE id = ?").run(iso(now), jobId);
}

export function failJob(db, job, message, now, { final = false } = {}) {
  const delay = final ? undefined : RETRY_DELAYS_MS[job.attempts - 1];
  if (delay === undefined) {
    db.prepare("UPDATE Job SET state = 'failed', error = ?, updatedAt = ? WHERE id = ?").run(message, iso(now), job.id);
    return "failed";
  }
  db.prepare("UPDATE Job SET state = 'queued', error = ?, runAfter = ?, updatedAt = ? WHERE id = ?").run(message, iso(now + delay), iso(now), job.id);
  return "retry";
}

// A YouTube rate limit is not the job's fault: it goes back without spending an attempt.
export function requeueRateLimited(db, job, untilMs, now) {
  db.prepare("UPDATE Job SET state = 'queued', attempts = MAX(attempts - 1, 0), runAfter = ?, error = 'YouTube rate limit — paused', updatedAt = ? WHERE id = ?")
    .run(iso(untilMs), iso(now), job.id);
}

export function pauseYoutube(db, untilMs, now) {
  db.prepare("UPDATE Job SET runAfter = MAX(runAfter, ?), updatedAt = ? WHERE state = 'queued' AND step = 'fetch'").run(iso(untilMs), iso(now));
  setSetting(db, "queuePausedUntil", untilMs);
}

export function recoverRunning(db, now) {
  return db.prepare("UPDATE Job SET state = 'queued', updatedAt = ? WHERE state = 'running'").run(iso(now)).changes;
}

export const latestJob = (db, videoId) => db.prepare("SELECT * FROM Job WHERE videoId = ? ORDER BY id DESC LIMIT 1").get(videoId) ?? null;

export const hasPendingJob = (db, videoId) => Boolean(db.prepare("SELECT 1 FROM Job WHERE videoId = ? AND state IN ('queued', 'running')").get(videoId));
```

```js
// The three steps of a video. Each one moves Video.state, stores what it made, queues the next.
import { enqueue } from "../jobs.mjs";
import { indexVideo } from "../search.mjs";
import { iso } from "../time.mjs";
import { parseVtt, transcriptText } from "../youtube/vtt.mjs";
import { trackCandidates } from "../youtube/ytdlp.mjs";
import { applyClassification } from "./classify.mjs";

export function createSteps({ db, youtube, summarize, classify, now = Date.now }) {
  const videoOf = (id) => db.prepare("SELECT * FROM Video WHERE id = ?").get(id);
  const setState = (id, state, error = null) =>
    db.prepare("UPDATE Video SET state = ?, error = ?, updatedAt = ? WHERE id = ?").run(state, error, iso(now()), id);

  async function fetchStep(video) {
    setState(video.id, "fetching");
    const meta = await youtube.fetchMetadata(video.id);
    db.prepare(`UPDATE Video SET title = ?, channel = ?, channelId = ?, durationS = ?, publishedAt = ?, chapters = ?, updatedAt = ? WHERE id = ?`)
      .run(meta.title, meta.channel, meta.channelId, meta.durationS, meta.publishedAt, JSON.stringify(meta.chapters), iso(now()), video.id);
    let chosen = null;
    let segments = [];
    let rateLimit = null;
    for (const track of trackCandidates(meta)) {
      let vtt;
      try {
        vtt = await youtube.downloadSubtitle(video.id, track);
      } catch (err) {
        if (err?.rateLimited) { rateLimit = err; continue; } // 429 is per language: try the next track
        throw err;
      }
      segments = parseVtt(vtt ?? "");
      if (segments.length) { chosen = track; break; }
    }
    if (!chosen) {
      if (rateLimit) throw rateLimit;
      setState(video.id, "no_transcript", "YouTube has no subtitles for this video.");
      return;
    }
    const text = transcriptText(segments);
    const language = chosen.lang.split("-")[0];
    db.transaction(() => {
      db.prepare(`INSERT INTO Transcript (videoId, language, kind, text, chars) VALUES (?, ?, ?, ?, ?)
                  ON CONFLICT(videoId) DO UPDATE SET language = excluded.language, kind = excluded.kind, text = excluded.text, chars = excluded.chars`)
        .run(video.id, language, chosen.kind, text, text.length);
      db.prepare("UPDATE Video SET language = ? WHERE id = ?").run(language, video.id);
      enqueue(db, { videoId: video.id, step: "summarize", now: now() });
    })();
    indexVideo(db, video.id);
    setState(video.id, "summarizing");
  }

  async function summarizeStep(video) {
    setState(video.id, "summarizing");
    const transcript = db.prepare("SELECT text FROM Transcript WHERE videoId = ?").get(video.id);
    if (!transcript) throw new Error("No transcript to summarize — retry the video.");
    const { markdown, model } = await summarize(videoOf(video.id), transcript.text);
    db.prepare(`INSERT INTO Summary (videoId, markdown, model, createdAt) VALUES (?, ?, ?, ?)
                ON CONFLICT(videoId) DO UPDATE SET markdown = excluded.markdown, model = excluded.model, createdAt = excluded.createdAt`)
      .run(video.id, markdown, model, iso(now()));
    indexVideo(db, video.id);
    if (videoOf(video.id).themeSource == null) {
      enqueue(db, { videoId: video.id, step: "classify", now: now() });
      setState(video.id, "classifying");
    } else {
      setState(video.id, "done");
    }
  }

  async function classifyStep(video) {
    setState(video.id, "classifying");
    const summary = db.prepare("SELECT markdown FROM Summary WHERE videoId = ?").get(video.id);
    if (!summary) throw new Error("No summary to classify — regenerate the summary.");
    const result = await classify(videoOf(video.id), summary.markdown);
    applyClassification(db, video.id, result, now());
    setState(video.id, "done");
  }

  const STEPS = { fetch: fetchStep, summarize: summarizeStep, classify: classifyStep };

  return {
    async run(job) {
      const video = videoOf(job.videoId);
      if (!video) return; // deleted meanwhile
      await STEPS[job.step](video);
    },
  };
}
```

```js
// What a failed step becomes: a pause (YouTube rate limit), a retry, or a failed video with its reason.
import { YOUTUBE_PAUSE_MS, failJob, pauseYoutube, requeueRateLimited } from "../jobs.mjs";
import { iso } from "../time.mjs";

const FINAL_CODES = new Set(["no_key", "bad_request"]);

export const isFinal = (err) => err?.unavailable === true || err?.missing === true || FINAL_CODES.has(err?.code);

export function handleFailure(db, job, err, now) {
  const message = String(err?.message ?? err).slice(0, 500);
  if (err?.rateLimited && job.step === "fetch") {
    const until = now + YOUTUBE_PAUSE_MS;
    pauseYoutube(db, until, now);
    requeueRateLimited(db, job, until, now);
    return "paused";
  }
  const outcome = failJob(db, job, message, now, { final: isFinal(err) });
  if (outcome === "failed") {
    db.prepare("UPDATE Video SET state = 'failed', error = ?, updatedAt = ? WHERE id = ?").run(message, iso(now), job.videoId);
  }
  return outcome;
}
```

```js
// The two gestures that put a video back to work: Retry, and Regenerate summary.
import { enqueue, hasPendingJob, latestJob } from "../jobs.mjs";
import { iso } from "../time.mjs";

const STATE_OF_STEP = { fetch: "queued", summarize: "summarizing", classify: "classifying" };

function requeue(db, videoId, step, now) {
  db.transaction(() => {
    enqueue(db, { videoId, step, now });
    db.prepare("UPDATE Video SET state = ?, error = NULL, updatedAt = ? WHERE id = ?").run(STATE_OF_STEP[step], iso(now), videoId);
  })();
}

export function retryVideo(db, videoId, now) {
  const video = db.prepare("SELECT state FROM Video WHERE id = ?").get(videoId);
  if (!video) throw new Error("Unknown video.");
  if (!["failed", "no_transcript"].includes(video.state) || hasPendingJob(db, videoId)) {
    throw new Error("Only a failed video can be retried.");
  }
  const last = latestJob(db, videoId);
  const step = video.state === "failed" && last?.state === "failed" ? last.step : "fetch";
  requeue(db, videoId, step, now);
}

export function regenerateSummary(db, videoId, now) {
  if (!db.prepare("SELECT 1 FROM Transcript WHERE videoId = ?").get(videoId)) throw new Error("This video has no transcript yet.");
  if (hasPendingJob(db, videoId)) throw new Error("This video is already being processed.");
  requeue(db, videoId, "summarize", now);
}
```

```js
// The worker: one job at a time, forever, until Ctrl-C. Run with `npm run worker` (or `npm run dev`).
import { openDb } from "../lib/db.mjs";
import { claimNext, completeJob, recoverRunning } from "../lib/jobs.mjs";
import { handleFailure } from "../lib/pipeline/failures.mjs";
import { createLivePipeline } from "../lib/pipeline/live.mjs";

const IDLE_MS = 2000;
const YOUTUBE_GAP_MS = 3000;
const sleep = (ms) => new Promise((r) => setTimeout(r, ms));

const db = openDb();
const recovered = recoverRunning(db, Date.now());
if (recovered) console.log(`[worker] put back ${recovered} job(s) left running`);
const { steps } = createLivePipeline(db);

let stopping = false;
for (const signal of ["SIGINT", "SIGTERM"]) process.on(signal, () => { stopping = true; });

let lastYoutubeAt = 0;
console.log("[worker] ready");
while (!stopping) {
  const job = claimNext(db, Date.now());
  if (!job) { await sleep(IDLE_MS); continue; }
  if (job.step === "fetch") {
    const wait = lastYoutubeAt + YOUTUBE_GAP_MS - Date.now();
    if (wait > 0) await sleep(wait);
  }
  const started = Date.now();
  try {
    await steps.run(job);
    completeJob(db, job.id, Date.now());
    console.log(`[worker] ${job.step} ${job.videoId} done in ${((Date.now() - started) / 1000).toFixed(1)}s`);
  } catch (err) {
    const outcome = handleFailure(db, job, err, Date.now());
    console.log(`[worker] ${job.step} ${job.videoId} ${outcome}: ${String(err?.message ?? err).slice(0, 200)}`);
  } finally {
    if (job.step === "fetch") lastYoutubeAt = Date.now();
  }
}
db.close();
console.log("[worker] stopped");
```

```js
// Pasted text → new videos in the queue. Lists are expanded by yt-dlp; a video already in the
// library (or twice in the paste) is counted, never queued again.
import { enqueue } from "./jobs.mjs";
import { iso } from "./time.mjs";
import { canonicalVideoUrl, parseInput } from "./youtube/urls.mjs";

export async function importInput(db, text, { listEntries, now }) {
  const items = parseInput(text);
  const invalid = items.filter((i) => i.kind === "invalid").map((i) => i.input);
  const errors = [];
  const entries = [];
  for (const item of items) {
    if (item.kind === "video") entries.push({ videoId: item.videoId, title: null });
    if (item.kind === "playlist" || item.kind === "channel") {
      try {
        entries.push(...(await listEntries(item.url)));
      } catch (err) {
        errors.push({ input: item.url, message: String(err?.message ?? err).slice(0, 300) });
      }
    }
  }
  if (!entries.length) return { batchId: null, imported: 0, skipped: 0, invalid, errors };
  const at = now();
  const counts = db.transaction(() => {
    const batchId = Number(db.prepare("INSERT INTO ImportBatch (input, videoCount, skippedCount, createdAt) VALUES (?, 0, 0, ?)").run(String(text).slice(0, 20_000), iso(at)).lastInsertRowid);
    const exists = db.prepare("SELECT 1 FROM Video WHERE id = ?");
    const insert = db.prepare("INSERT INTO Video (id, url, title, state, importBatchId, createdAt, updatedAt) VALUES (?, ?, ?, 'queued', ?, ?, ?)");
    const seen = new Set();
    let imported = 0;
    let skipped = 0;
    for (const e of entries) {
      if (seen.has(e.videoId) || exists.get(e.videoId)) { skipped++; continue; }
      seen.add(e.videoId);
      insert.run(e.videoId, canonicalVideoUrl(e.videoId), e.title ?? null, batchId, iso(at), iso(at));
      enqueue(db, { videoId: e.videoId, step: "fetch", now: at });
      imported++;
    }
    db.prepare("UPDATE ImportBatch SET videoCount = ?, skippedCount = ? WHERE id = ?").run(imported, skipped, batchId);
    return { batchId, imported, skipped };
  })();
  return { ...counts, invalid, errors };
}
```

```js
// Every read the pages and the MCP server make. Plain SQL, one place.
import { getSetting } from "./settings.mjs";
import { ftsQuery } from "./search.mjs";
import { findThemeByPath, listThemes, themePath } from "./themes.mjs";

const ACTIVE = "('queued','fetching','summarizing','classifying')";
const VIDEO_STATES = ["queued", "fetching", "summarizing", "classifying", "done", "no_transcript", "failed"];

const pathSql = "CASE WHEN p.id IS NULL THEN t.name ELSE p.name || ' › ' || t.name END";
const videoSelect = `
  SELECT v.*, ${pathSql} AS themePath, COALESCE(c.cost, 0) AS costMicrousd
  FROM Video v
  LEFT JOIN Theme t ON t.id = v.themeId
  LEFT JOIN Theme p ON p.id = t.parentId
  LEFT JOIN (SELECT videoId, SUM(costMicrousd) AS cost FROM ApiCall GROUP BY videoId) c ON c.videoId = v.id`;

export function listVideos(db, { themeId = null, state = null, q = null, limit = 500 } = {}) {
  const where = [];
  const params = { limit };
  if (Number.isInteger(themeId)) {
    where.push("(v.themeId = @themeId OR v.themeId IN (SELECT id FROM Theme WHERE parentId = @themeId))");
    params.themeId = themeId;
  }
  if (state === "active") where.push(`v.state IN ${ACTIVE}`);
  else if (state === "review") where.push("v.themeSource = 'proposed'");
  else if (VIDEO_STATES.includes(state)) { where.push("v.state = @state"); params.state = state; }
  const match = q ? ftsQuery(q) : "";
  if (match) { where.push("v.id IN (SELECT videoId FROM SearchIndex WHERE SearchIndex MATCH @match)"); params.match = match; }
  return db.prepare(`${videoSelect} ${where.length ? `WHERE ${where.join(" AND ")}` : ""} ORDER BY v.createdAt DESC, v.id LIMIT @limit`).all(params);
}

export function getVideo(db, id) {
  const video = db.prepare(`${videoSelect} WHERE v.id = ?`).get(id);
  if (!video) return null;
  const transcript = db.prepare("SELECT text FROM Transcript WHERE videoId = ?").get(id);
  const summary = db.prepare("SELECT markdown, model FROM Summary WHERE videoId = ?").get(id);
  const lastJob = db.prepare("SELECT * FROM Job WHERE videoId = ? ORDER BY id DESC LIMIT 1").get(id) ?? null;
  return { ...video, transcript: transcript?.text ?? null, summary: summary?.markdown ?? null, summaryModel: summary?.model ?? null, lastJob };
}

export function themeTree(db) {
  const themes = listThemes(db);
  const byId = new Map(themes.map((t) => [t.id, t]));
  const counts = new Map(db.prepare("SELECT themeId, COUNT(*) AS n FROM Video WHERE themeId IS NOT NULL GROUP BY themeId").all().map((r) => [r.themeId, r.n]));
  const node = (t) => ({
    id: t.id, name: t.name, path: themePath(t, byId), parentId: t.parentId,
    videoCount: counts.get(t.id) ?? 0, sheetGeneratedAt: t.sheetGeneratedAt, changesSinceSheet: t.changesSinceSheet, children: [],
  });
  const roots = themes.filter((t) => t.parentId == null).map(node);
  const rootById = new Map(roots.map((r) => [r.id, r]));
  for (const t of themes) if (t.parentId != null) rootById.get(t.parentId)?.children.push(node(t));
  return roots;
}

export function getTheme(db, id) {
  const theme = db.prepare("SELECT * FROM Theme WHERE id = ?").get(id);
  if (!theme) return null;
  const byId = new Map(listThemes(db).map((t) => [t.id, t]));
  return {
    ...theme,
    path: themePath(theme, byId),
    children: db.prepare("SELECT id, name FROM Theme WHERE parentId = ? ORDER BY name COLLATE NOCASE").all(id),
    videos: db.prepare(`${videoSelect} WHERE v.themeId = ? ORDER BY v.title COLLATE NOCASE`).all(id),
  };
}

export function themeVideosWithSummaries(db, themeId) {
  return db.prepare(`SELECT v.*, s.markdown AS summary FROM Video v LEFT JOIN Summary s ON s.videoId = v.id
                     WHERE v.themeId = ? ORDER BY v.publishedAt, v.id`).all(themeId);
}

export function findTheme(db, { themeId = null, name = null } = {}) {
  if (Number.isInteger(themeId)) return db.prepare("SELECT * FROM Theme WHERE id = ?").get(themeId) ?? null;
  if (!name?.trim()) return null;
  const [a, b] = name.split("›").map((s) => s.trim());
  if (b) return findThemeByPath(db, b, a);
  return findThemeByPath(db, a) ?? db.prepare("SELECT * FROM Theme WHERE name = ? COLLATE NOCASE ORDER BY id LIMIT 1").get(a) ?? null;
}

export function reviewQueue(db) {
  return db.prepare(`${videoSelect} WHERE v.themeSource = 'proposed' ORDER BY v.updatedAt, v.id`).all().map((v) => {
    let proposal = null;
    try { proposal = JSON.parse(v.proposedTheme ?? "null"); } catch { proposal = null; }
    return { ...v, proposal };
  });
}

export function libraryCounts(db) {
  return db.prepare(`SELECT COUNT(*) AS total,
                            COALESCE(SUM(themeSource = 'proposed'), 0) AS review,
                            COALESCE(SUM(state = 'failed'), 0) AS failed,
                            COALESCE(SUM(state IN ${ACTIVE}), 0) AS active,
                            COALESCE(SUM(state = 'no_transcript'), 0) AS noTranscript
                     FROM Video`).get();
}

export function queueStatus(db, now) {
  const until = getSetting(db, "queuePausedUntil");
  return {
    pausedUntil: Number.isFinite(until) && until > now ? until : null,
    pendingJobs: db.prepare("SELECT COUNT(*) FROM Job WHERE state IN ('queued','running')").pluck().get(),
  };
}
```

```jsx
import { useRouter } from "next/navigation";
import { useEffect } from "react";

// While the worker has something to do, the page re-reads itself every few seconds.
export default function AutoRefresh({ active, everyMs = 4000 }) {
  const router = useRouter();
  useEffect(() => {
    if (!active) return undefined;
    const id = setInterval(() => router.refresh(), everyMs);
    return () => clearInterval(id);
  }, [active, everyMs, router]);
  return null;
}
```

```jsx
"use client";

import { useMemo, useRef, useState } from "react";
import { lineSeconds } from "@/lib/youtube/timestamps.mjs";
import Markdown from "./Markdown";

export default function VideoWorkspace({ videoId, summary, transcript }) {
  const frame = useRef(null);
  const [tab, setTab] = useState(summary ? "sheet" : "transcript");
  const [filter, setFilter] = useState("");
  const lines = useMemo(
    () => (transcript ?? "").split("\n").filter(Boolean).map((line) => ({ line, s: lineSeconds(line) })),
    [transcript],
  );
  const needle = filter.trim().toLowerCase();
  const shown = needle ? lines.filter((l) => l.line.toLowerCase().includes(needle)) : lines;

  const seek = (seconds) => {
    const send = (func, args = []) => frame.current?.contentWindow?.postMessage(JSON.stringify({ event: "command", func, args }), "*");
    send("seekTo", [seconds, true]);
    send("playVideo");
  };

  return (
    <div className="grid gap-6 lg:grid-cols-2">
      <div className="lg:sticky lg:top-6 lg:self-start">
        <div className="aspect-video overflow-hidden rounded-lg bg-black">

            ref={frame}
            src={`https://www.youtube.com/embed/${videoId}?enablejsapi=1`}
            title="YouTube player"
            allow="autoplay; encrypted-media; picture-in-picture"
            allowFullScreen
            className="h-full w-full"
          />
        </div>
      </div>
      <div className="min-w-0">
        <div className="flex gap-2 border-b border-neutral-200">
          {[["sheet", "Sheet"], ["transcript", "Transcript"]].map(([key, label]) => (
```

```js
// What Claude Code can read from the library — pure functions over a read-only database.
import { videoSheetFile, themeSheetFile } from "../lib/export.mjs";
import { findTheme, getTheme, getVideo, themeTree } from "../lib/queries.mjs";
import { searchVideos } from "../lib/search.mjs";
import { lineSeconds, parseTimestamp } from "../lib/youtube/timestamps.mjs";

const plural = (n, word) => `${n} ${word}${n === 1 ? "" : "s"}`;
const sheetState = (t) => {
  if (!t.sheetGeneratedAt) return "none";
  const day = t.sheetGeneratedAt.slice(0, 10);
  return t.changesSinceSheet ? `${day}, ${plural(t.changesSinceSheet, "change")} since` : day;
};

export function listThemesText(db) {
  const tree = themeTree(db);
  if (!tree.length) return "The library has no theme yet.";
  const line = (t, indent) => `${indent}- ${t.path} (themeId ${t.id}, ${plural(t.videoCount, "video")}, sheet: ${sheetState(t)})`;
  return tree.flatMap((root) => [line(root, ""), ...root.children.map((c) => line(c, "  "))]).join("\n");
}

export function searchText(db, { query, limit = 10 }) {
  const hits = searchVideos(db, query, limit);
  if (!hits.length) return `No video matches "${query}".`;
  return hits.map((h) => {
    const v = getVideo(db, h.videoId);
    return `- ${v?.title ?? h.videoId} (videoId ${h.videoId}) — theme: ${v?.themePath ?? "unsorted"}\n  ${h.snippet}`;
  }).join("\n");
}

export function videoSheetText(db, { videoId }) {
  const v = getVideo(db, videoId);
  if (!v) return `No video with id ${videoId}.`;
  if (!v.summary) return `"${v.title ?? videoId}" has no sheet yet (state: ${v.state}).`;
  return videoSheetFile({ video: v, summary: v.summary, themePath: v.themePath, model: v.summaryModel }).content;
}

export function themeSheetText(db, { themeId = null, name = null }) {
  const found = findTheme(db, { themeId, name });
  if (!found) return `No theme matches ${themeId != null ? `id ${themeId}` : `"${name}"`}. Call list_themes to see them.`;
  const theme = getTheme(db, found.id);
  const sheet = theme.sheetMarkdown
    ? themeSheetFile({ path: theme.path, sheetMarkdown: theme.sheetMarkdown, model: theme.sheetModel, generatedAt: theme.sheetGeneratedAt, videoCount: theme.videos.length }).content
    : `# ${theme.path}\n\nNo consolidated sheet yet — regenerate it in DataTube, or read the video sheets below with get_video_sheet.\n`;
  const stale = theme.sheetMarkdown && theme.changesSinceSheet
    ? `\n> Note: ${plural(theme.changesSinceSheet, "video change")} since this sheet was written.\n`
    : "";
  const videos = theme.videos.map((v) => `- ${v.title ?? v.id} (videoId ${v.id})`).join("\n") || "(no video)";
  return `${sheet}${stale}\n## Videos in this theme\n${videos}\n`;
}

export function transcriptRangeText(db, { videoId, from = null, to = null }) {
  const v = getVideo(db, videoId);
  if (!v) return `No video with id ${videoId}.`;
  if (!v.transcript) return `"${v.title ?? videoId}" has no transcript (state: ${v.state}).`;
  const start = from ? parseTimestamp(from) : null;
  const end = to ? parseTimestamp(to) : null;
  if ((from && start == null) || (to && end == null)) return "from and to are timestamps like 12:34 or 1:02:03.";
  const lines = v.transcript.split("\n").filter((line) => {
    const s = lineSeconds(line);
    return s != null && (start == null || s >= start) && (end == null || s <= end);
  });
  return lines.length ? lines.join("\n") : "No transcript line in that range.";
}
```

```js
// DataTube's MCP server (stdio, read-only). Claude Code starts it:
//   claude mcp add datatube -- node /absolute/path/to/DataTube/mcp/server.mjs
// stdout carries the protocol: log with console.error only.
import { fileURLToPath } from "node:url";
import { McpServer } from "@modelcontextprotocol/sdk/server/mcp.js";
import { StdioServerTransport } from "@modelcontextprotocol/sdk/server/stdio.js";
import { z } from "zod";
import { openDb } from "../lib/db.mjs";
import { listThemesText, searchText, themeSheetText, transcriptRangeText, videoSheetText } from "./tools.mjs";

const file = process.env.DATATUBE_DB?.trim() || fileURLToPath(new URL("../data/datatube.db", import.meta.url));
let db = null;
const library = () => {
  db ??= openDb(file, { readonly: true });
  return db;
};

const reply = (fn) => async (args) => {
  try {
    return { content: [{ type: "text", text: fn(library(), args ?? {}) }] };
  } catch (err) {
    const empty = /unable to open|no such file|SQLITE_CANTOPEN|does not exist/i.test(String(err?.message));
    return {
      content: [{ type: "text", text: empty ? "The DataTube library is empty — import videos in the app first." : `DataTube error: ${String(err?.message ?? err).slice(0, 300)}` }],
      isError: !empty,
    };
  }
};

const VideoId = z.string().regex(/^[A-Za-z0-9_-]{11}$/).describe("The 11-character YouTube id");
const Stamp = z.string().describe("A timestamp like 12:34 or 1:02:03");

const server = new McpServer({ name: "datatube", version: "1.0.0" });

server.registerTool("list_themes", {
  title: "List themes",
  description: "The themes of Robin's YouTube knowledge library (Parent › Child), with their ids, video counts and the date of their consolidated sheet.",
  inputSchema: {},
}, reply((lib) => listThemesText(lib)));

server.registerTool("search", {
  title: "Search the library",
  description: "Full-text search over video titles, knowledge sheets and transcripts. Returns video ids to read with get_video_sheet or get_transcript.",
  inputSchema: { query: z.string().min(1), limit: z.number().int().min(1).max(50).optional() },
}, reply(searchText));

server.registerTool("get_video_sheet", {
  title: "Read a video's knowledge sheet",
  description: "One video's sheet: core idea, chapters, key points and practical steps, every point cited as [MM:SS] \"exact words\" from the transcript.",
  inputSchema: { videoId: VideoId },
}, reply(videoSheetText));

server.registerTool("get_theme_sheet", {
  title: "Read a theme's consolidated sheet",
  description: "The consolidated sheet of a theme — knowledge merged across its videos, cited as [Video title · MM:SS], disagreements listed — plus its videos. Give themeId, or name as \"Parent › Child\" or just the name.",
  inputSchema: { themeId: z.number().int().optional(), name: z.string().optional() },
}, reply(themeSheetText));

server.registerTool("get_transcript", {
  title: "Read a transcript",
  description: "A video's timestamped transcript, whole or between two timestamps — to check the exact wording behind a sheet's citation.",
  inputSchema: { videoId: VideoId, from: Stamp.optional(), to: Stamp.optional() },
}, reply(transcriptRangeText));

await server.connect(new StdioServerTransport());
console.error(`[datatube-mcp] ready on ${file}`);
```
