# Summary Format — YTQuest

## Structure

```
## 📋 Résumé — "[Video Title]"

**Auteur :** Name | **Durée :** ~XX min | **Langue :** XX | **Segments :** N

### 🎯 Concept / Thème
One paragraph capturing the video's core idea.

### 🏗️ Architecture / Key Components
Table or bullet list of main building blocks.

### 📊 Sections / Loops / Chapters
Each major topic with its timestamp range and key points.
Use markdown tables for structured data.
Use bold for key metrics, costs, tools.

### 💡 Key Points / Takeaways
Actionable advice, quotes, resources mentioned.

### 🛠️ Getting Started
Step-by-step or links to resources.
```

## Formatting rules

- **Emoji headers**: One emoji per section for visual scanning
- **Markdown tables**: Use pipe tables for comparisons, specs, loops
- **Timestamps**: Include for each major section transition
- **French summaries**: Default to French unless video is in another language
- **Concise**: Each bullet/row is one line, no filler
